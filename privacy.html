home-383-rclone - Privacy Policy

Last updated: 7 November 2026

Who uses this app

This app is used only by its owner, with the owner's own Google account.

What Google user data the app accesses

With the owner's consent, the app accesses files and file metadata in the owner's Google Drive so they can be read, written and moved from the owner's PC.

How the data is used and stored

Data moves only between Google Drive and the owner's own computer. Copies of recently used files are cached on that computer's local disk. The app does not send Google user data to any other server or third party, and does not use it for advertising or analytics.

Sharing

Google user data is not shared, sold or transferred to anyone.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact

Questions can be raised through the GitHub repository that hosts this page.
